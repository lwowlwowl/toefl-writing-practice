# TOEFL iBT Writing Practice

> Systematic practice repository for TOEFL iBT Writing section — **Write an Email** & **Writing for an Academic Discussion**, with AI-powered analysis and feedback.

## About

This repository is a structured practice space for the two essay-type tasks in the TOEFL iBT Writing section. Each practice entry goes beyond simply writing a response — every submission is analyzed by AI across multiple dimensions including word count, grammar, vocabulary, academic conventions, coherence, and rubric-aligned scoring.

## Workflow

1. **Pick a topic** — Choose an unpracticed topic from either `email/` or `academic-discussion/`.
2. **Read the prompt** — Open `prompt.md` and understand the scenario / discussion context.
3. **Write under timed conditions** — Email: 7 minutes; Academic Discussion: 10 minutes.
4. **Save your response** — Write it in `response.md` (record your actual writing time).
5. **Run AI analysis** — Use the prompt from `prompts/` to get detailed feedback, save it in `analysis.md`.
6. **Review & reflect** — Study the feedback, note recurring issues, and track progress.

## AI Analysis Dimensions

Each response is analyzed across the following dimensions:

| Dimension | Description |
|-----------|-------------|
| **Word Count** | Total words, sentence count, average sentence length |
| **Grammar** | Subject-verb agreement, tense consistency, article usage, punctuation |
| **Vocabulary** | Lexical diversity (TTR), academic word usage, precision, collocations |
| **Coherence & Cohesion** | Logical flow, transition usage, paragraph structure |
| **Task Fulfillment** | How well the response addresses all parts of the prompt |
| **Tone & Register** | Appropriateness for the task context (email vs. academic) |
| **Rubric Score** | Estimated 0-5 score with justification |

## Scoring Scale

Both tasks use a **0–5 rubric**:

| Score | Level | Description |
|-------|-------|-------------|
| 5 | Strong | Fully addresses task; clear, well-organized; strong language control |
| 4 | Good | Effectively addresses task; adequate development; minor errors |
| 3 | Fair | Addresses task with limited development; noticeable errors |
| 2 | Limited | Partially addresses task; frequent errors interfere with meaning |
| 1 | Minimal | Minimally addresses task; serious language errors |
| 0 | — | No response, off-topic, or not in English |
