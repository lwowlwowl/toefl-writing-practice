# Writing for an Academic Discussion — 评分标准（0-5 分）

> 基于 ETS 官方 2026 新托福 Writing Rubric（[原文 PDF](https://www.ets.org/pdfs/toefl/writing-rubrics.pdf)）翻译整理。建议最低字数：100 词。

## 5 分 — 完全成功的回答（A fully successful response）

回答与讨论高度相关、表达非常清晰，是一次有质量的在线讨论贡献，且语言运用水平稳定。

典型表现：
- 解释、举例和/或细节相关且充分展开
- 有效运用多种句式结构，用词精准、地道
- 几乎没有词汇或语法错误，仅存在限时写作中可预期的小瑕疵（如常见拼写错误或 there/their 混用）

## 4 分 — 基本成功的回答（A generally successful response）

回答与讨论相关，是一次有价值的在线讨论贡献，语言运用水平足以让读者轻松理解。

典型表现：
- 解释、举例和/或细节相关且展开适当
- 使用了多种句式结构，用词恰当
- 词汇或语法错误较少

## 3 分 — 部分成功的回答（A partially successful response）

回答大体相关、基本可理解，是一次在线讨论的贡献，具备一定的语言运用能力。

典型表现：
- 解释、举例或细节可能存在部分缺失、不清晰或不相关之处
- 句式结构有一定变化，词汇量有一定范围
- 存在一些明显的词汇和语法错误（句子结构、词形或习语使用方面）

## 2 分 — 大体不成功的回答（A mostly unsuccessful response）

回答反映了参与在线讨论的意图，但语言运用的局限性可能导致意思难以跟读。

典型表现：
- 观点展开不充分或仅部分相关
- 句式结构和词汇范围有限
- 句子结构、词形或用法错误不断积累

## 1 分 — 不成功的回答（An unsuccessful response）

回答反映了一次不成功的在线讨论参与尝试，语言运用的局限性可能阻碍了思想的表达。

典型表现：
- 有些词语和短语显示出回应题目的意图，但几乎没有连贯的想法
- 句式结构和词汇范围极度有限
- 语言使用中存在严重且频繁的错误
- 原创语言极少；任何连贯的语言基本都是从题目中借用的

## 0 分 — 无法评分的回答（No scorable response）

回答为空白、拒绝题目、非英文写作、完全抄袭题目、与题目完全无关或由随意敲击键盘组成。

## Academic Discussion 核心要求

学术讨论任务要求考生在 **10 分钟** 内阅读教授提出的问题和两位同学的回复，然后写出自己的讨论贡献。建议最低 **100 词**。

与邮件写作的关键区别在于：学术讨论更强调**对讨论的贡献质量**，包括与其他同学观点的互动、原创性表达、以及论证的展开深度。

## 评分维度速查

| 维度 | 评分关注点 |
|------|-----------|
| **相关性与贡献度** | 回复是否直接回应教授的问题？是否对讨论有实质性贡献？ |
| **论证展开** | 解释、举例和细节是否充分、具体？ |
| **讨论互动** | 是否与教授或同学的观点产生了互动？ |
| **原创性** | 是否用自己的话表达？照搬题目语言会直接扣分 |
| **句式多样性** | 是否混合运用了简单句、并列句和复合句？ |
| **用词精准度** | 用词是否准确、地道？ |
| **语法控制** | 错误的频率和严重程度如何？是否影响理解？ |

## 邮件写作 vs 学术讨论：评分侧重点对比

| 评分维度 | 邮件写作 | 学术讨论 |
|---------|---------|---------|
| 核心考察点 | 沟通有效性 | 学术贡献质量 |
| 语气与表达风格 | 符合邮件写作规范 | 符合学术讨论规范 |
| 原创性要求 | 用自己的语言清晰表达 | 不得照搬题目或同学的表达，原创性是关键评分维度 |
| 情境互动 | 针对具体情境作出回应 | 结合教授问题和同学观点展开互动 |
| 字数要求 | 无明确最低字数 | 至少 100 词 |
| 句式多样性 | 有价值但非重点 | 作为独立评分维度明确列入标准 |
